# hugo-haku

A radically minimalist theme for the modern [Hugo](https://gohugo.io) implementation (v0.146+).

hugo-haku is a modified version of [lugo](https://github.com/LukeSmithxyz/lugo)
by Luke Smith, licensed under the GNU General Public License v3.0. See LICENSE.

Mahjong tile images in `static/tiles/` are from
[riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)
by FluffyStuff, released into the public domain (CC0).
